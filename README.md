# 🛒 Multi-Shop POS Billing System (Streamlit + Supabase)

A fast, lightweight, and bilingual (**English** & **Português**) Point of Sale (POS) billing and reporting system built with **Streamlit** and **Supabase**, tailored for multi-shop retail operations in Brazil (`America/Sao_Paulo` timezone).

---

## ✨ Key Features

- **🌐 Instant Bilingual Switch (`E` / `P`)**: Toggle the entire user interface and payment method labels between **English** and **Português** with one click while maintaining consistent database keys in Supabase.
- **🏪 Multi-Shop Support**: Switch seamlessly between **Main Shop** and **Second Shop** with isolated daily/monthly reporting and safe entry deletion.
- **🇧🇷 Brazil Timezone Ready**: Automatically defaults to `America/Sao_Paulo` local date.
- **🧾 Fast Billing & Cart Management**:
  - Look up products by unique `code` and add integer quantities.
  - Automatic quantity aggregation for duplicate items, individual item removal, and whole-integer discount calculation.
- **💳 Brazilian Payment Methods**:
  - **Cash (`Dinheiro`)**: Built-in **Cash Given** & **Change (`Troco`)** calculator.
  - **Pix (`Pix`)**
  - **Debit Card (`Débito`)**
  - **Credit Card 1x (`Crédito à Vista`)**
  - **Credit Card Installments (`Crédito Parcelado`)**: Dynamic installment counter (`Parcelas`).
- **📊 Date-Range Sales Analytics & CSV Export**:
  - Filter sales by custom **Start Date** to **End Date** or jump to the **Full Current Month** in one click.
  - Live breakdown cards for each payment method + **Grand Total**.
  - Export filtered transactions to `.csv` or delete erroneous entries by **Sale ID**.
- **📧 Automated Daily & Monthly Email Reports**:
  - One-click **Send Daily Report** and **Send Monthly Report** buttons that send structured JSON summaries to **Make.com** (or any webhook) via HTTP `POST`.

## 🗄️ Supabase Database Setup

Run the following SQL in your **Supabase SQL Editor** to create the required `products` and `sales` tables:

```sql
-- 1. Products Table
CREATE TABLE products (
    code TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    price INTEGER NOT NULL
);

-- 2. Sales Table
CREATE TABLE sales (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    sale_date DATE NOT NULL,
    shop_name TEXT NOT NULL,
    items_summary TEXT NOT NULL,
    subtotal INTEGER NOT NULL,
    discount INTEGER NOT NULL DEFAULT 0,
    total_bill INTEGER NOT NULL,
    payment_method TEXT NOT NULL,
    installments INTEGER NOT NULL DEFAULT 1
);
```

## ⚙️ Installation & Local Setup

1. **Clone or download the project files** into a folder:
   ```bash
   git clone <your-repo-url>
   cd pos-billing-system
   ```

2. **Install the required packages**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Configure Streamlit Secrets**:
   Create a file at `.streamlit/secrets.toml` and add your Supabase and Make.com webhook credentials:
   ```toml
   SUPABASE_URL = "https://supabase.co"
   SUPABASE_KEY = "your-supabase-anon-or-service-key"
   MAKE_WEBHOOK_URL = "https://make.com"
   ```

4. **Run the application**:
   ```bash
   streamlit run app.py
   ```

---

## 📡 Webhook JSON Payload Format

When clicking **Send Daily Report** or **Send Monthly Report**, the app sends a `POST` request with the following JSON structure to `MAKE_WEBHOOK_URL`:

```json
{
  "report_type": "daily",
  "period": "2026-11-22",
  "shop": "Main Shop",
  "total_sales": 1450,
  "transactions_count": 8
}
```
*(For monthly reports, `"report_type"` is `"monthly"` and `"period"` is formatted as `"YYYY-MM"`.)*

## 🚀 Deployment (Streamlit Community Cloud)

1. Push `app.py`, `database.py`, `requirements.txt`, and `README.md` to a **GitHub** repository.
2. Go to [share.streamlit.io](https://streamlit.io) and connect your repository.
3. In **App Settings → Secrets**, paste the contents of your `secrets.toml` file and click **Deploy**.
